# sDisplay 更新目录

此目录只服务 sDisplay，不与仓库中的其他软件共享清单、更新资产或版本号。

`archive/` 保留更名前的原始安装包、增量包和清单，保留原始字节和签名，不用于 sDisplay 更新。此次更改了应用内部标识，需要手动安装全量包，并重新设置开机启动和偏好设置。旧客户端的更新地址不再使用。

- `sDisplay/appcast.xml`：sDisplay 客户端读取的 Sparkle 更新清单。
- `sDisplay/releases/<版本>/sDisplay-<版本>.zip`：该版本的完整更新包。
- `sDisplay/releases/<版本>/*.delta`：后续同一应用标识的版本可提供增量更新，跨越 3 个以上版本使用全量更新。
- Sparkle EdDSA 签名使用钥匙串账户 `ed25519`；私钥不得写入仓库或发布资产。

版本目录和其中资产一经发布即不可覆盖；任何修订必须使用更高的显示版本和构建号。Sparkle 更新包签名不等于 Apple 公证，本包使用本地临时签名，未经过 Apple 公证。

其他软件必须使用各自的顶级目录，禁止修改、复用或引用本目录中的清单和资产。
